# VanillaJS To-do Lists

VanillaJS To-do Lists is a portfolio frontend demo. Built in JavaScript with no
runtime dependencies, it uses native Web Components, Shadow DOM and
`localStorage` to manage multiple lists and their items.

This documentation has three parts.
